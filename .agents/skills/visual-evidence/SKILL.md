# Visual evidence

1. Use the repository's PNG capture workflow; screenshots are the required deliverable, not video.
2. Confirm the workflow ran on the exact branch HEAD being reviewed.
3. Download and inspect each PNG and the contact sheet. Check that frames show actual gameplay, not splash/blank/menus unless those are the intended target.
4. Inspect framing, ship visibility, target acquisition, HUD clipping, contrast, environment exposure, and renderer.
5. Record image dimensions, artifact/run ID, renderer, and any frames that fail review.
6. A capture workflow exit code is not enough: inspect the images. Do not claim a full mission playthrough from a short deterministic capture.
