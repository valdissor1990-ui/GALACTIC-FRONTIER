# GALACTIC FRONTIER

Оригинальная одиночная космическая action-RPG с открытым миром. Платформа — Windows PC. Движок — Godot 4.7.2-stable, основной язык — GDScript.

## Неизменяемые правила
- Только бесплатные инструменты и зависимости с открытыми лицензиями.
- Не использовать Unreal Engine, Unity, платные плагины и платные ассеты.
- Оригинальная вселенная. Не копировать охраняемые элементы Freelancer или других игр.
- Offline-first: без обязательного интернета, серверов, аккаунтов, телеметрии и микротранзакций.
- Владелец не устанавливает инструменты и не пишет код вручную. Работа ведётся через ChatGPT и Grok с фиксацией в GitHub.
- Не называть код собранным или проверенным без реального запуска. Различать статическую проверку и runtime-тест.

## Текущий статус

- Стартовый экран: новая игра, продолжение из quick save, справка по управлению и выход.
- Вертикальный срез **The Silent Relay**: игровой полёт, навигационный маяк, сканирование, две серии боевых столкновений и возвращение к орбитальному носителю.
- Сохранение контрольной точки: F5 — быстрый слот, F9 — загрузка. Во время боевой волны при загрузке волна создаётся заново; отдельное состояние каждого противника пока не сохраняется.
- Процедурный резервный вид кораблей игрока и Raider используется, если Godot не может импортировать GLB.
- Godot CI проверяет скрипты и сцены, тесты полёта/боя/сохранений и экспорт Windows. Полный статус последнего запуска см. во вкладке [Actions](https://github.com/valdissor1990-ui/GALACTIC-FRONTIER/actions).

## Управление

| Клавиша | Действие |
|---|---|
| W / S | Вперёд / назад |
| A / D | Стрейф влево / вправо |
| Space / Z | Вверх / вниз |
| Q / E | Рыскание |
| I / K | Тангаж |
| J / L | Крен |
| Shift | Форсаж |
| X | Торможение |
| C | Переключение внешней и cockpit-камеры |
| ЛКМ | Основное оружие |
| T / Y | Захват / сброс цели |
| F | Сканирование маяка или объекта |
| F5 / F9 | Быстрое сохранение / загрузка |
| [ / ] | Чувствительность мыши |

Сборка остаётся одиночной и автономной: сохранения хранятся локально в `user://saves`.
