Оригинальная одиночная космическая action-RPG с открытым миром. Платформа — Windows PC. Движок — Godot 4.7.2-stable, основной язык — GDScript.

## Неизменяемые правила
- Только бесплатные инструменты и зависимости с открытыми лицензиями.
- Не использовать Unreal Engine, Unity, платные плагины и платные ассеты.
- Оригинальная вселенная. Не копировать охраняемые элементы Freelancer или других игр.
- Offline-first: без обязательного интернета, серверов, аккаунтов, телеметрии и микротранзакций.
- Владелец не устанавливает инструменты и не пишет код вручную. Работа ведётся через ChatGPT и Grok с фиксацией в GitHub.
- Не называть код собранным или проверенным без реального запуска. Различать статическую проверку и runtime-тест.
