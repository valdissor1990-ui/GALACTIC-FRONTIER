## Правило завершения

Работа по графике не считается законченной по факту успешной компиляции. Для каждого пункта должны быть одновременно выполнены:
1. Реализация в ресурсах/сценах/шейдерах.
2. Успешная проверка импорта и запуска Godot.
3. Скриншоты 1920×1080 из реальной сцены.
4. Проверка крупных и игровых дистанций.
5. Отсутствие регрессий производительности и игровых систем.

Нельзя отмечать пункт как PASS только по наличию кода или GLB-файла. До визуальной проверки статус остаётся NOT VERIFIED.
