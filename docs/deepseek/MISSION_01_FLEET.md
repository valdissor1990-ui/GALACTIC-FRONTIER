# DeepSeek Mission 01 — Завершить производственный пайплайн флота GALACTIC FRONTIER

Проект: Godot 4.7.2, GDScript, Blender Python. Выполни крупную работу в репозитории, не ограничивайся советами.

1. Аудируй scripts/blender/build_player_fighter.py, build_enemy_interceptor.py, build_fleet_expansion.py, сцены ships/combat, workflow Blender/Godot, тесты и project.godot.
2. Исправь генерацию семи оригинальных кораблей: геометрия, нормали, root hierarchy, bounds, камера, свет, PBR материалы, силуэты и функциональные детали. Единые ориентация, масштаб, naming.
3. Все семь кораблей должны headless генерироваться в Blender, экспортироваться в GLB и иметь полноценные PNG превью с кораблём целиком в кадре.
4. Проверь реальные GLB assets и пути сцен. Создай data-driven реестр флота с классом, ролью, игровыми параметрами скорости/прочности/массы, габаритами и mount points. Не выдавай игровые значения за физические измерения.
5. Создай reusable Godot ship definitions/resources без дублирования логики. Сохрани совместимость с flight controls и combat AI.
6. Для боевых кораблей добавь collision shapes и markers оружия/двигателей/hardpoints; для крупных — применимые точки турелей, двигателей и ангаров. Не имитируй неподключённые функции.
7. Добавь проверки GLB/сцен/реестра/битых путей и headless Godot import; Blender smoke checks, где возможно.
8. Обнови документацию по добавлению кораблей, запуску генерации и CI.
9. Только оригинальный дизайн. Не копируй Star Wars/Venator/Freelancer и не используй сторонние ассеты с неизвестной лицензией.

Приёмка: все 7 кораблей в реестре, GLB, сцены и непустые превью; Blender build и Godot import проходят; существующие тесты не ломаются. Чётко разделяй статический анализ, headless тест и интерактивный playtest. Не заявляй непроверенное.

Изучи проект, составь план и выполни задачу за один проход. Меняй файлы, запускай тесты, не трогай main, секреты и настройки безопасности, не сливай PR. Верни только git-apply-compatible unified diff, без Markdown fences.
